# Boundary and Refusal Practice Guide

拒绝或表达边界时，可以使用“明确回应、简短理由、可选替代”的结构。理由不需要无限解释，也不需要保证对方一定满意。

示例表达：

- “谢谢你想到我，但这次我不能参加。”
- “我今晚需要休息，暂时不能帮忙。”
- “这个话题我不太想继续聊，我们可以换一个话题。”
- “我现在不能答应；如果之后时间合适，我再主动联系你。”

可以先练习写出一句不带攻击性的拒绝，再进行角色扮演。用户可以跳过理由、暂停练习或选择更温和的版本。练习目标是清楚表达自己的选择，不是控制对方情绪。
