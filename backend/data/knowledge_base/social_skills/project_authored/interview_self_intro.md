# Interview Self Introduction Practice Guide

面试自我介绍可以先准备一个短版本，只包含当前身份、一个相关经历和求职方向。先保证结构清楚，再逐步增加细节。

简短结构：

- 当前身份：“我是……专业的本科生。”
- 相关经历：“最近完成了一个……项目，主要负责……”
- 求职方向：“我希望继续学习……方向的开发和评测。”

低强度练习可以从写三句话开始，再录一次音，最后进行模拟问答。卡住时可以使用：“我先从最近的项目经历说起。”完成标准是清楚说完核心信息，而不是一次表现得完全自然。
