# Group Discussion Practice Guide

小组讨论练习可以先从“补充一个点”开始，不需要一开始就承担总结或主导任务。发言前写下一句核心观点，并准备一个与前面同学衔接的开场。

可用表达：

- “我补充一个比较小的点。”
- “我同意刚才关于……的部分，另外我想到……”
- “我还没想完整，先说一个初步方向。”

低强度步骤可以是先在纸上写一句、向熟悉同学复述，再在小组中完成一次简短表达。成功标准是说出一个清楚观点，而不是控制所有人的反应。用户可以随时暂停或把任务降为书面整理。
