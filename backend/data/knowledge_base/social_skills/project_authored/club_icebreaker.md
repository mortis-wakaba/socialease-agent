# Club Icebreaker Practice Guide

社团破冰不需要立刻进行长对话，可以从环境相关的问题或简短自我介绍开始。选择容易回答、不会涉及隐私的问题，能让双方都有退出空间。

可用表达：

- “你好，我是第一次参加这个活动，你之前来过吗？”
- “我叫……，是……专业的。你是怎么知道这个社团的？”
- “刚才那个环节挺有意思的，你觉得怎么样？”

低强度练习可以是先完成一次点头问候，再问一个简单问题。成功标准是完成一次友好的开场，而不是保证对话持续很久；对方回应简短也不代表练习失败。
