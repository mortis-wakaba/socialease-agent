# Asking a Teacher Practice Guide

向老师提问时，可以把问题压缩成“背景一句、问题一句”。如果担心当场表达，可以先写好关键词，或选择课后、邮件等较低强度方式。

示例结构：

- “老师，我对刚才的例子有一点没理解。”
- “我想确认一下，这里的条件是不是只适用于……？”
- “如果现在不方便，我也可以课后再请教。”

练习可以从把问题写下来开始，再低声读一遍，最后选择合适时机问出一句。完成标准是提出一个具体问题，不要求措辞完美；如果压力过高，可以暂停并改用书面方式。
