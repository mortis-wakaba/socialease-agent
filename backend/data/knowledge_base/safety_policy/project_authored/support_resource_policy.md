# Support Resource Policy

Support-resource navigation in SocialEase Agent follows these project rules:

- ordinary support queries may only retrieve verified public resources from `support_resources`;
- when the knowledge base lacks enough evidence, the system must return unknown instead of inventing contacts, offices, or services;
- crisis-like input must pause ordinary retrieval and enter crisis escalation first;
- campus-specific resources are not included until a verified institutional import and review process exists;
- citations should expose source identity and source type so users can distinguish external public resources from project-authored policy or demo material.

This policy defines product behavior. It does not create or certify any real-world support service.
