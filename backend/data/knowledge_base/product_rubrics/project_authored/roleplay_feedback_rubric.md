# Roleplay Feedback Rubric

Role-play feedback in SocialEase Agent is structured around four non-clinical dimensions:

- clarity: whether the user's main point is understandable;
- naturalness: whether the wording sounds usable in ordinary conversation;
- assertiveness: whether the user can express a need or boundary clearly;
- empathy: whether the wording acknowledges the other person where appropriate.

The implementation must prefer privacy-safe derived features over stored raw practice text.
Useful signals include message length buckets, sentence count, question count, first-person
markers, reason markers, request markers, boundary markers, empathy markers, politeness
markers, specificity markers, collaborative markers, and repair or acknowledgement markers.
These signals should support feedback consistency without preserving the user's original
practice sentence.

The rubric is for product feedback consistency only. It is not a mental-health assessment.
