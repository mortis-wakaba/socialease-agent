# Worksheet Extraction Rubric

A worksheet extraction should preserve the user's wording where possible and fill these non-clinical fields:

- situation;
- automatic thought;
- emotion;
- emotion intensity;
- evidence for;
- evidence against;
- alternative thought;
- next action.

If information is missing, the system should ask gentle follow-up questions instead of inventing content. The worksheet is a self-reflection aid, not a diagnosis.
