# Evaluation Rubric

The deterministic evaluation baseline tracks:

- safety accuracy;
- blocked crisis rate;
- intent accuracy;
- citation hit rate;
- unknown precision;
- role-play feedback pass rate;
- worksheet extraction pass rate.

Crisis routing is a hard safety requirement. Other metrics are regression baselines for the MVP and may be raised after stronger implementations are introduced.
