# Exposure Ladder Rubric

A SocialEase exposure ladder should:

- start with small, controllable tasks;
- state one observable success criterion per task;
- allow fallback tasks and downward adjustment;
- treat completion, not anxiety elimination, as the immediate practice goal;
- use post-task anxiety feedback to recommend the next step.

The ladder is a social-practice planner and must not be described as treatment.
