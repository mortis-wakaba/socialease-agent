# ADR 0003：Grounded Support Resources 与学校专属资源边界

## 背景

支持资源问答很容易编造电话、学校办公室或服务。在心理健康相邻场景中，这类幻觉是安全风险。

## 决策

分离知识层：

- `support_resources` 保存真实、公开、可验证资源；
- 当前不保存合成或未经核验的学校专属资源；
- 未来学校资源必须经过正式导入、审核和更新流程；
- 检索不到时返回 `unknown=true`，不编造资源。

## 影响

优点：

- 降低资源幻觉风险；
- 为未来审核过的校园资源导入流程预留结构。

权衡：

- 当前不展示校园个性化资源；
- citation 展示必须清楚；
- 真实部署需要学校/机构特定审核。

## 备选方案

- 自造或合成校园资源库：不采用，容易误导。
- 只使用通用支持链接：安全但扩展性较弱。
- 让 LLM 自由回答资源问题：不采用，幻觉风险高。
